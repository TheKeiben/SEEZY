================================================================================
Windows Local Inference Module README
================================================================================

Directory Overview
------------------
This directory serves as the local testing and validation environment for the trained YOLOv8 model. It allows developers to test webcam integration, bounding box accuracy, and detection logic on a Windows PC before deploying code to the Jetson Orin Nano hardware.

File Overview
-------------
* config.py: Centralized configuration file storing camera indices, confidence thresholds, timeout limits, and required consecutive detection streaks.
* items.py: A simple dictionary mapping the integer class IDs to their string names (e.g., milk, ketchup).
* detector.py: The core algorithmic logic. It manages the camera stream, processes YOLO predictions, and enforces the consecutive-frame stability logic before confirming a successful detection.
* test_detector.py: A wrapper script to instantiate the model and execute the `detect_item()` function from `detector.py`.
* live_inference.py: A standalone, continuous video feed script that overlays bounding boxes and calculates local FPS for quick visual debugging.

Setup & Installation
--------------------
* Requires a local Python virtual environment.
* Dependencies: `ultralytics`, `opencv-python` (cv2).
* A dedicated NVIDIA GPU (CUDA) is highly recommended for smooth local testing, though it will fall back to CPU.

How to Use / Execution
----------------------
* Run `python live_inference.py` for an endless visual stream to test model accuracy in real-time.
* Run `python test_detector.py` to test the state-machine logic (searching for a specific item ID and timing out if not found).

Dependencies & Interactions
---------------------------
* Depends on the `best.pt` weights generated by the Training module.
* Acts as the algorithmic blueprint for the production `vision_node.py` deployed on the Linux architecture.
